# AI CODE: HUMAN VS MACHINE

Українськомовна інтерактивна презентація навчального дослідження безпеки Python-коду. React + Vite, Lucide React, Recharts, адаптивний CSS. Сервер і база даних не потрібні.

## Локальний запуск

Node.js 22.12+ або 24 LTS, npm.

```sh
npm ci
npm run dev
```

Команди `npm run build` і `npm run preview` створюють і переглядають production-збірку. У середовищі з недоступним домашнім каталогом використовуйте `npm ci --cache /tmp/ai-code-npm`.

## Перевірки

```sh
npm test
npx playwright test
```

Перед першою браузерною перевіркою: `npx playwright install chromium`. Playwright сам запускає Vite. Для встановленого системного Chromium: `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`. Тести перевіряють навігацію, вкладки, демонстрацію, звіти, мобільну версію та reduced motion.

## Редагування

- `src/data.js`: інструменти, навчальний код, вразливості, учасники, сценарні оцінки й дані автора.
- `src/main.jsx`: секції та інтерактивні компоненти.
- `src/styles.css`: палітра, адаптивна верстка, анімації.

Усі оцінки, знахідки учасників і час — **демонстраційні**, а не результати фактичних запитів до моделей. Програвач не виконує Python і не звертається до API. При внесенні реальних результатів необхідно змінити відповідні підписи та задокументувати методику, версії моделей, дату, запити й спосіб оцінювання. Python-приклад навмисно вразливий і не призначений для використання в реальному застосунку.

Особисті дані автора не вигадані: замініть заповнювачі в `author`. Мультимедіа залишено у вигляді підписаних контейнерів. Скриншот-референс не був наданий. Зовнішні зображення не використовуються; Google Fonts необов’язкові, є системні резервні шрифти.
